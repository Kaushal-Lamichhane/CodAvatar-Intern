# Frontend Development Internship — TaskFlow Dashboard

An 8-week frontend development journey focused on building a practical TaskFlow Dashboard while learning modern frontend technologies.

## 🎯 Project Goal

Build a responsive task management dashboard with reusable components, interactive features, and API integration while developing real-world frontend development skills.

## 🛠️ Tech Stack

- HTML5 & CSS3
- JavaScript (ES6+)
- TypeScript
- React
- Tailwind CSS
- REST APIs
- GraphQL & Apollo Client
- Git & GitHub

## 🗺️ Learning Roadmap

| Week | Focus |
|---|---|
| 1 | HTML, CSS & Responsive Design | 
| 2 | JavaScript Fundamentals & Behavior |
| 3 | TypeScript |
| 4 | React Fundamentals |
| 5 | React Hooks & State Management |
| 6 | Routing & UI Development |
| 7 | APIs, GraphQL & Apollo Client |
| 8 | Testing, Debugging & Final Project |

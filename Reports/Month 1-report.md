## 3. Major Practical Project — Task Management Dashboard

During Week 4, I worked on a Task Management Dashboard to apply the React and TypeScript concepts learned throughout the internship.

### Features implemented

- Create new tasks.
- Update and edit task titles.
- Mark tasks as completed or pending.
- Delete existing tasks.
- Filter tasks by All, Pending and Completed status.
- Validate task titles before submission.
- Display appropriate feedback for invalid inputs.
- Handle empty task lists and empty filter results.
- Organize the application into reusable React components.

### Technical implementation

| **Area** | **Implementation** |
|---|---|
| UI | React and JSX |
| Language | TypeScript |
| State management | React `useState` |
| Component communication | Props and callback functions |
| Data updates | Immutable state updates |
| List rendering | `.map()` and unique keys |
| Filtering | `.filter()` |
| Validation | Task title validation (5–80 characters) |
| Code quality | ESLint |
| Build tool | Vite |

### Concepts applied

The project helped me understand how state is managed in React, how components communicate with each other, and how user actions update the interface.

I also learned why state should be updated immutably and why shared state should be managed by the appropriate parent component.

# TaskFlow Component Tree

## Component Hierarchy

```text
App
└── Dashboard
    └── TaskList
        ├── TaskCard (Learn React)
        ├── TaskCard (Practice TypeScript)
        └── TaskCard (Build Dashboard)
```

## Component Responsibilities

| Component | Responsibility |
|---|---|
| App | Root application component |
| Dashboard | Displays dashboard layout and heading |
| TaskList | Stores and renders the task dataset |
| TaskCard | Displays an individual task |

## Concepts Practiced

- JSX expressions
- React functional components
- Component composition
- Props and TypeScript interfaces
- Rendering lists with map()
- Stable keys
- Semantic HTML elements

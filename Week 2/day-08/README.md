# Day 08 — Arrays, Objects and Modules

## Goal
Practice transforming task data and organizing reusable JavaScript functions into modules.

## Completed
- [x] Filter tasks by status using `filter()`
- [x] Extract task titles using `map()`
- [x] Find tasks by ID using `find()`
- [x] Count tasks by status using `reduce()`
- [x] Sort tasks by priority without modifying the original array
- [x] Extract object properties using destructuring
- [x] Export and import reusable functions

## Edge Cases Tested
- [x] Missing task ID returns `undefined`
- [x] Empty task counts return `{}`
- [x] Sorting an empty array returns `[]`
- [x] Original task order remains unchanged

## Files
- `tasks.js` — Sample task data
- `transformation.js` — Reusable task transformation functions
- `main.js` — Imports, function calls and tests

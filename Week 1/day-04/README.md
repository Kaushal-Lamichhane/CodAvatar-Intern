# Day 04 — Flexbox, Grid & Responsive Design

## Objective
Build a responsive TaskFlow dashboard that adapts to mobile, tablet, and desktop screens.

## Concepts Learned
- **Flexbox:** Main axis, cross axis, alignment, spacing, and wrapping.
- **CSS Grid:** Grid tracks, columns, rows, and card layouts.
- **Responsive Design:** Media queries and breakpoints.
- **Fluid Layouts:** Flexible widths and `minmax()`.
- **Accessibility:** Text wrapping, keyboard focus, and reachable controls.
- **Overflow:** Identifying and preventing unwanted horizontal scrolling.

## Viewport Comparison

| Device | Viewport Width | Expected Layout |
|---|---:|---|
| Mobile | 375px | Sidebar stacks above content; one card column |
| Tablet | 768px | Layout adapts to the available width |
| Desktop | 1440px | Sidebar and main content appear side by side |

## Key Takeaways
Flexbox is useful for arranging elements along one main axis, while CSS Grid is useful for creating row-and-column layouts. Media queries allow the design to adapt to different screen sizes.
